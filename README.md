# Open-Source Projects, Organizations and Hackathons/Events on HCB

This (awesome) list maintains a list of open-source projects and organizations fiscally sponsored through [HCB](https://hackclub.com/fiscal-sponsorship), Hack Club's fiscal sponsorship program.

## Rationale

Currently there's no way to identify if an HCB organization is identified as an open-source project/organization via the official HCB ([context at Hack Clib Slack](https://hackclub.slack.com/archives/C0188CY57PZ/p1732718394916749?thread_ts=1732718394.916749&cid=C0188CY57PZ)), hence setting this Awesome list up.
